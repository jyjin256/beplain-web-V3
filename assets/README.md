## 서체 Riant Display Trial
CDN이 없어서 지금은 컴퓨터에 설치된 경우에만 보여요(없으면 Pretendard). 쓰려면 폰트 파일(woff2)을 `assets/fonts/`에 넣고 `styles.css` 맨 아래에 `@font-face`를 추가해요. 이름에 Trial이 붙은 서체는 보통 개인 시험용이라, 공개 사이트에 쓰기 전에 라이선스를 확인해 주세요.
